COMO RODAR
---------
Backend (Django):
  cd backend && ../.venv/bin/python manage.py test
  (defaults já apontam para o Postgres de dev em localhost:5432)

IAM:
  cd iam && python manage.py test

Seeds (populam dados de teste):
  IAM:    Get-Content testes/seeds/seed_demo.py | docker compose exec -T iam python manage.py shell
  backend: Get-Content testes/seeds/seed_demo_data.py | docker compose exec -T erp python manage.py shell

testes/seeds/seed_demo.py  — SEED DA IAM (identidade / SSO)
-----------------------------------------------------------------
Popula tenants, módulos, papéis de fábrica e usuários de demonstração.
Idempotente (get_or_create). Roda dentro do container IAM.

Tenants criados:
  - demo (Empresa Demo) — módulos: drone, erp_financeiro, crm, rh
  - acme (Empresa Acme) — módulos: drone

Usuários criados:
  - demo     / demo123     → tenant demo | 9 papéis | 90 permissões
  - admin    / admin123     → tenant demo | tenant_admin | 101 permissões
  - semdrone / semdrone123  → tenant demo | papel: operacional (mascaramento)
  - acme     / acme123      → tenant acme | papel: operacional

Comando interno: sync_authz (sincroniza catálogo de permissões + papéis de fábrica).

testes/seeds/seed_demo_data.py  — SEED DO backend (dados de negócio)
-----------------------------------------------------------------
Popula dados de negócio no backend para o tenant "demo". Idempotente
(get_or_create). Roda sob rls_bypass() para contornar a RLS do PostgreSQL.

Itens criados:
  - 2 Empreendimentos (Residencial Vista Verde, Comercial Centro Norte)
  - 3 Obras com 9 etapas (Torre A — Fundações, Torre B — Alvenaria, Galeria)
  - 4 Clientes com 4 aquisições e 4 contratos (João, Maria, Carlos, Ana)
  - 3 Funcionários com 3 cargos (Pedro, Raimundo, Cláudia)
  - 5 Eventos de calendário (reuniões, tarefas, lembretes)
  - 4 Notificações (2 não-lidas, 2 lidas)

backend/create_superuser.py  — Cria superusuário do backend
-----------------------------------------------------------------
Script auxiliar para criar um superuser local do Django (admin de plataforma).
